# backend

Repositorio ficticio para la API del proyecto.

## Objetivo

Centralizar la lógica de negocio, endpoints REST, integraciones y acceso a base de datos.

## Plantillas incluidas

- Issue template
- Pull request template
- Labels del proyecto
- Milestones
- Regla de protección de ramas: `RP-02`

## Milestones

- Hito 1: Kickoff y arquitectura base
- Hito 2: API core y autenticación
- Hito 3: Frontend web MVP
- Hito 4: Integración con servicios externos
- Hito 5: PWA y experiencia móvil
- Hito 6: QA, hardening y lanzamiento

## Protección de rama

Se exige 1 revisión antes de fusionar cambios en la rama principal.
